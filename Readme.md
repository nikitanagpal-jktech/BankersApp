# NIDHI BANK

A banker-facing Core Banking System built using React, Node.js, Express, TypeScript, PostgreSQL and Drizzle ORM.

## Features

- Banker authentication
- Customer management
- Savings and Current accounts
- Deposits and withdrawals
- Fund transfers
- Transaction history
- Account 360 / Passbook
- Loan sanction and disbursal
- EMI schedule generation
- Full and partial EMI payments

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express
- TypeScript
- Drizzle ORM

### Database
- PostgreSQL
